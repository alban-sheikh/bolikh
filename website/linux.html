Bolikh / Linux

Bolikh for Linux · free

Dictation for Linux, offline, on X11 and Wayland.

Bolikh is a free, open-source dictation app for Linux. Hold the Right Ctrl key, speak, and let go: your words are typed wherever your cursor is, in your browser, editor, chat app or terminal. Speech is turned into text on your own machine, so it works without the internet and your voice is never uploaded.

Linux

Ubuntu 24.04 or later, Debian 13, Fedora 40 or later. 64-bit Intel or AMD PCs, X11 and Wayland.

Download .deb (Ubuntu, Debian)Download .rpm (Fedora)

Install the package, then join the input group.

Why use Bolikh on Linux

X11 and Wayland

Bolikh works on both. On Wayland it types through wtype or ydotool; on X11 it needs nothing extra.

Works in terminals

Bolikh notices when the focused window is a terminal and pastes with Ctrl+Shift+V. You can also set the paste shortcut yourself in Settings.

Open source

The full source is on GitHub under GPL-3.0, so you can read exactly what it does with your microphone and build it yourself.

Text that reads as written

Bolikh removes “um” and “uh”, adds punctuation, writes numbers as digits and understands commands such as “new line” and “bullet point”.

Set up Bolikh on Linux

Bolikh reads the dictation key directly from the keyboard, so your user must be in the input group. The setup below shows the one command for that.

  1. 1

    Install the package

    On Ubuntu or Debian:

    sudo apt install ./Bolikh-linux-amd64.deb

    On Fedora:

    sudo dnf install ./Bolikh-linux-x86_64.rpm
  2. 2

    Give Bolikh keyboard access

    Bolikh reads the dictation key directly from the keyboard, which works on both X11 and Wayland. Add yourself to the input group, then log out and back in:

    sudo usermod -aG input $USER
  3. 3

    Wayland only: install a paste helper

    Check which session you’re running:

    echo $XDG_SESSION_TYPE

    If it says x11, skip this step. On Wayland, install wtype for KDE Plasma, Sway or Hyprland. On GNOME, install ydotool and make sure its ydotoold service is running.

    sudo apt install wtype
  4. 4

    Microphone and speech model

    Open Bolikh, click Test and say a few words to check the microphone. Then let it download the speech model once (about 670 MB).

  5. 5

    Try it

    Click in the practice box, hold Right Ctrl, say a sentence and let go. Bolikh then waits in the system tray.

Problems and fixes on Linux

The key does nothing on Linux

Run groups and check that input is in the list. If you only just added it, log out and back in. On Wayland, also check that wtype or ydotool is installed. Bolikh’s setup screen shows which of these is missing.

Linux says there are dependency problems

Install with apt rather than dpkg -i: sudo apt install ./Bolikh-linux-amd64.deb downloads everything Bolikh needs from your distribution. If you already used dpkg, run sudo apt -f install to finish. On Fedora, dnf install handles this automatically.

Linux shows an error mentioning GLIBC

Your distribution is older than Bolikh supports (for example Ubuntu 22.04 or Debian 12). Bolikh needs Ubuntu 24.04, Debian 13, Fedora 40 or newer.

There’s no tray icon on Linux

Ubuntu shows tray icons out of the box. On GNOME in Fedora or Arch, install the AppIndicator extension. Without a tray, Bolikh keeps its window open so you can still reach Settings.

Dictation doesn’t work in a Linux terminal

Linux terminals paste with Ctrl+Shift+V, not Ctrl+V. From version 0.2.5 Bolikh checks which window is focused and uses the right one. If text still doesn’t appear, update to the latest version first. Bolikh can’t see the focused window on GNOME with Wayland, or inside an editor’s built-in terminal such as VS Code’s; for those, open Settings and set Paste shortcut to Ctrl+Shift+V while you work in the terminal. On X11, installing xdotool makes the check more reliable.
