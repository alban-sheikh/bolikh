Bolikh / Windows

Bolikh for Windows · free

Voice typing for Windows that works offline, in every app.

Bolikh is a free dictation app for Windows 10 and 11. Hold the Right Ctrl key, speak, and let go: your words are typed wherever your cursor is, in Outlook, Word, Teams, Slack, your browser or a terminal. Speech is turned into text on your PC, so it works without the internet and your voice is never uploaded.

Windows

Windows 10 or 11, 64-bit.

Download for Windows

Run the installer. No admin rights needed.

Why use Bolikh on Windows

One key, any app

Hold Right Ctrl to talk and release to type. It works in any app where you can type, and you can change the key or switch to press-once-to-start in Settings.

No account, no internet

There is nothing to sign in to. After the one-time speech model download (about 670 MB), dictation keeps working with the network switched off.

Text that reads as written

Bolikh removes “um” and “uh”, adds punctuation, writes numbers as digits and understands commands such as “new line” and “bullet point”.

Installs for you only

The installer doesn’t ask for administrator rights, so it also works on a work PC where you can’t install system-wide software.

Set up Bolikh on Windows

Windows needs no special permissions. Bolikh only needs to be able to use your microphone, which Windows allows for desktop apps by default.

  1. 1

    Install

    Run the Bolikh setup file. It installs for your account only, so you don’t need admin rights.

    If Windows shows “Windows protected your PC”, see the question about it below.

  2. 2

    Check the microphone

    Open Bolikh, click Test and say a few words. Bolikh tells you when the microphone works.

    If it says it’s very quiet or can’t find a microphone, go to Settings → Privacy & security → Microphone and turn on “Let desktop apps access your microphone”.

  3. 3

    Let the speech model download

    Bolikh downloads its speech model once (about 670 MB) and shows the progress. After that it works offline. Windows needs no other permissions.

  4. 4

    Try it

    Click in the practice box, hold Right Ctrl, say a sentence and let go. Bolikh then waits in the system tray. If you can’t see its icon, click the ^ arrow next to the clock.

Problems and fixes on Windows

Windows shows “Windows protected your PC”

Click More info, then Run anyway. You only need to do this the first time.

The Windows installer wants to download WebView2

Bolikh’s window uses Microsoft Edge WebView2, which Windows 11 and most updated Windows 10 PCs already have. If yours doesn’t, the installer downloads it from Microsoft automatically. This needs an internet connection and only happens once.

Windows says VCRUNTIME140.dll or MSVCP140.dll is missing

Bolikh installs these Microsoft files next to itself, so this shouldn’t happen. If it does, uninstall Bolikh, install it again, and if the message stays, install the Microsoft Visual C++ Redistributable (x64) from Microsoft’s website, then restart your PC.

The key works in most apps but not in one

Windows doesn’t let normal apps type into apps that run as administrator. Run that app normally, or right-click Bolikh and choose Run as administrator too.
